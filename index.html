Saya adalah mahasiswa

Halo! Saya Nisriin Arafat Abdurrahman, mahasiswa Pendidikan Sistem dan Teknologi Informasi di UPI Kampus Purwakarta. Saya sedang belajar mengembangkan kemampuan pemrograman web. Selama mengikuti praktikum pemrograman internet, saya mulai mempelajari cara membuat website dari dasar. Saya belajar menggunakan HTML untuk menyusun struktur halaman, CSS untuk mengatur tampilan, JavaScript untuk menambahkan interaksi, dan Bootstrap untuk membantu membuat desain website yang lebih menarik dan responsif. Dari proses belajar ini, saya mulai memahami bagaimana setiap teknologi saling melengkapi dalam pembuatan sebuah website.

My Learning Journey

HTML🌐

Saya mulai belajar membuat struktur dasar website menggunakan HTML, seperti menambahkan judul, paragraf, gambar, tautan, dan berbagai elemen lainnya.

CSS🎨

Saya belajar mengatur tampilan website menggunakan CSS, mulai dari memilih warna, mengatur ukuran teks, hingga menyesuaikan tata letak agar terlihat lebih menarik.

JavaScript⚙️

Saya mulai mengenal JavaScript untuk membuat website lebih interaktif, seperti menambahkan fungsi pada tombol dan membuat halaman merespons tindakan pengguna.

Bootstrap📱

Saya mempelajari Bootstrap untuk membantu membuat tampilan website dengan lebih praktis, terutama dalam menyusun layout dan membuat tampilan yang menyesuaikan ukuran layar.
